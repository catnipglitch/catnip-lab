# catnip-lab

[Catnipのテックログ](https://catnipglitch.dev)（ブログ）の記事で配布するサンプルコード・サンプル HTML・エージェントスキルなどの置き場です。

## フォルダ構成

記事 1 本につきフォルダ 1 つを `yyyy/mm/slug/` の形式で切っています。`slug` は記事 URL の末尾と対応します。

```
2026/
  08/
    cf-builds-mcp/   ← https://catnipglitch.dev/cf-builds-mcp/ の配布物
```

## 凍結ポリシー

各フォルダの中身は**記事公開時点のスナップショット**で、公開後は更新しません。記事の記述とコードの整合性を保つためです。

- 不具合が見つかった場合も上書きせず、フォルダ内に注記（errata）を追記します
- 開発が続いているものは、最新版へのリンクを各フォルダの README か記事本文に記載します
